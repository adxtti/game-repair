# Rewind game updates

Rewind downloads the required game update from this repository before online or offline play. Use Update Game in the current Rewind launcher while NBA 2K19 is closed.

The update replaces the eight installation files and six runtime files under data/steam, including both steam_api64.dll copies. Existing career saves and unrelated game archives are retained. Replacement files are verified during download and existing files are backed up before installation.

The release contains only the game repair files. Rewind launcher updates are published separately. Server packages, account data, saves, and operator keys must stay private.
